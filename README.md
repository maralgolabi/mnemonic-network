# Mnemonic Network

A generative fictional archive connecting photographs of strangers
through invented memories.

Inspired by Maria Stepanova's exploration of memory, photographs,
family archives, and reconstruction in *In Memory of Memory*.

## Concept

Each photograph enters the archive as an anonymous subject.

An AI system extracts visual motifs, retrieves related fragments from
the existing archive, and generates fictional memories that connect
otherwise unrelated people.

Memories may contradict each other, decay over time, or be inherited
through other memories.

## Architecture

Photo
→ Visual Observer
→ Motif Extraction
→ Memory Retrieval
→ Memory Generation
→ Contradiction Detection
→ Memory Graph
